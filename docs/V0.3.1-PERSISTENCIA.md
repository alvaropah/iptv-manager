# v0.3.1 — Persistencia

GitHub Actions intenta restaurar `catalog.db` al iniciar y publica la BD al finalizar.
El Core usa una capa de almacenamiento intercambiable, por lo que posteriormente
podemos mover la BD a un servidor, bucket, Cloudflare, PostgreSQL/Supabase u otro
backend sin cambiar la lógica del catálogo.

GitHub Artifacts es una solución de transición para esta fase, no el alojamiento final.
