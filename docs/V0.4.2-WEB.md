# v0.4.2 — Primera interfaz web

La primera UI se sirve en `/ui/` mediante FastAPI StaticFiles y consume la API `/api/*`.

Incluye dashboard, buscador, películas, series, categorías, fichas de contenido, versiones/fuentes y temporadas/episodios. El botón de reproducción abre el `playback_url` almacenado por el catálogo.

La UI no consulta Xtream directamente.
