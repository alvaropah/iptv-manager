# Paso 5.5 — Resolución de fuentes y versiones

Esta prueba formaliza tres niveles:

**Contenido → Fuente/versión → Stream**

Un mismo contenido puede tener:
- varias categorías/procedencias;
- varias calidades o características técnicas;
- varios streams dentro de una misma categoría.

La prueba clasifica las coincidencias reales en:
1. variantes técnicas;
2. fuentes/categorías diferentes;
3. posibles streams duplicados.

No fusiona ni elimina entradas. El objetivo es validar el modelo que después
podrá representarse en la interfaz como un selector de fuente/calidad.
