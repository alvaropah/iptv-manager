# Paso 5.2 — Identidad y variaciones de títulos

Valida la generación de una identidad canónica para candidatos de contenido.

Se prueban variantes de calidad/técnicas, idioma, año y SxxExx. La normalización
sirve para generar candidatos; no implica que dos obras sean automáticamente
la misma. Los casos ambiguos deben quedar para una fase posterior de resolución.

Regla: **normalizar no significa fusionar**.
