# v0.4 — API Foundation

La v0.4 introduce la primera API del IPTV Manager sobre el catálogo persistido.

## Principio

`Xtream → sincronizador → BD → API → futura interfaz web`

La API **no consulta Xtream para servir el catálogo**. Xtream solo interviene en
la sincronización.

## Endpoints iniciales

- `GET /`
- `GET /api/health`
- `GET /api/stats`
- `GET /api/categories`
- `GET /api/search?q=...`
- `GET /api/movies/{id}`
- `GET /api/series/{id}`
- `GET /api/series/{id}/seasons`
- `GET /api/episodes/{id}`

Los detalles de películas y episodios incluyen las versiones y sus streams.

## Ejecutar localmente

```bash
uvicorn app.main:app --reload
```

Después se puede abrir `/docs` para consultar la documentación OpenAPI.
