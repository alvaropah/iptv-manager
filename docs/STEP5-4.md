# Paso 5.4 — Auditoría completa de identidad

Recorre todas las categorías SERIES y VOD seleccionadas y aplica la identidad
canónica a todo el catálogo devuelto por Xtream.

Muestra:
- entradas totales;
- identidades únicas;
- contenidos presentes en 2+ categorías;
- conflictos donde la misma identidad canónica aparece con años explícitamente distintos;
- duplicados que no presentan señales técnicas diferentes.

Es una auditoría. No fusiona contenidos, no genera una base de datos final y
no modifica ninguna playlist.
