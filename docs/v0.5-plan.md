# IPTV Manager v0.5 — Biblioteca

Objetivo: convertir la base API de v0.4.3 en una biblioteca navegable sobre el catálogo SQLite real.

## Alcance

- Listado paginado de películas y series.
- Búsqueda paginada y filtrable por tipo.
- Filtrado por categoría.
- Ficha de película con versiones y streams.
- Ficha de serie con temporadas y episodios.
- Selector de fuentes/calidades sin duplicar contenido.
- Interfaz web consumiendo exclusivamente la API.
- Sin consultas a Xtream durante la navegación.

## Arquitectura

SQLite → Repository → FastAPI → UI.

La API limita el tamaño de cada respuesta para evitar cargar el catálogo completo en el navegador.
