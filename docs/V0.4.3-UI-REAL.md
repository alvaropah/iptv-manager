# v0.4.3 — UI sobre catálogo real

La restauración del catálogo utiliza el mismo mecanismo probado en v0.3.1/v0.4.1:
`gh run list` + `gh run download`, con permisos `actions: read`.

La ejecución busca primero `iptv-manager-v031-catalog` en la última ejecución exitosa de
`03-1-sync-persistent.yml` y usa `iptv-manager-v03-catalog` como fallback.

No se consulta Xtream ni se modifica la BD.
