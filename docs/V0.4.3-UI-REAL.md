# v0.4.3 — UI sobre catálogo real

La restauración busca hasta 10 ejecuciones exitosas de v0.3.1 y valida cada artifact
antes de aceptarlo. La BD solo se copia a `data/iptv_manager.db` si contiene el
esquema persistente de la aplicación (`content`, `version`, `stream`, `season`,
`episode`, `episode_version`, `episode_stream`, `category`) y supera `PRAGMA
integrity_check`.

Si ninguna ejecución v0.3.1 es compatible, se prueban hasta 10 ejecuciones de v0.3
como fallback.

No se consulta Xtream ni se modifica la BD persistente remota.
