# v0.4.1 — API sobre catálogo real

Esta versión valida la API contra la base de datos persistida por la sincronización v0.3/v0.3.1.

No ejecuta sincronización Xtream y no modifica la base de datos. El workflow recupera primero el artifact persistido más reciente y después prueba endpoints sobre datos reales.

La recuperación prioriza `iptv-manager-v031-catalog` y usa `iptv-manager-v03-catalog` como fallback.


### Corrección 0.4.1-fix
La prueba de búsqueda usa `normalized_title`, que es el campo sobre el que trabaja el endpoint `/api/search`. Así no se seleccionan como semilla prefijos técnicos que la identidad canónica haya eliminado.
