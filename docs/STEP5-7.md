# Paso 5.7 — Preview de importación del catálogo

Simula la futura importación sobre el catálogo real seleccionado.

Recorre las categorías seleccionadas, calcula identidades, agrupa entradas,
detecta versiones y descubre episodios de series.

El resultado es exclusivamente un **preview**. No escribe registros en una
base de datos persistente, no elimina duplicados y no modifica ninguna
playlist.

Este paso sirve para comprobar qué estructura produciría el importador antes
de activar la importación real.
